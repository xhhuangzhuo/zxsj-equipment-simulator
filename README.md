# 诛仙世界装备属性模拟器

一个纯前端的网页工具, 帮你快速算出诛仙世界里装备搭配后的副属性总和, 方便对比不同配置。

## 在线访问

**https://zxsj-zbmnq-s4.netlify.app/**

微信里点开直接用, 无需安装。

## 主要功能

- **15 个装备槽位** (头/衣/手/武器/腰/腿/脚/护符×2/法印/令牌/项链/手腕/天灵/地宝), 完整模拟
- **稀有装备** 支持 (稀有护符 4 维, 稀有项链/令牌/法印 中中小/大小小)
- **多方案管理** 新建/重命名/删除/导出/导入, 一键对比不同配装思路
- **配套系统** 机巧盘 / 丹药 / 食物 / 符文 / 稀有护符额外 / 铭锋 全支持
- **强化计算** `k = 0.03n + 0.12` 公式精确 (误差 <0.15%)
- **数据本地保存** localStorage, 关掉浏览器不丢

## 使用方法

1. 浏览器打开上面的在线地址, 或者直接双击 `index.html` 也能跑
2. 点"新建"创建你的方案
3. 配置装备 (装等/类型/词条/强化), 选稀有, 配机巧盘/丹药/食物/符文
4. 点"计算属性"查看总分和分项明细
5. 点"保存配置"自动存到 localStorage

## 数据来源

所有数值来自游戏实测, 缺失档位按线性规律外推, 外推值会在游戏内测到准确值后更新。

**已知是外推值的位置** (后续会更新):
- 护符2 575/580 装等 (按 G1 线性外推)
- 护符1 稀有 535/540/555/560/565 基础值 (用户给 530/545/550/570, 其余插值)
- G3 565 装等 (按 560→570 折半推理)

## 文件结构

```
.
├── index.html         # 入口
├── styles.css         # 样式
├── data.js            # 装备数据 / 强化公式 / 常量
├── logic.js           # 计算逻辑
├── app.js             # UI 交互 + 状态管理
├── char.png           # 中间角色图
└── deploy/            # 部署版本 (和根目录一致, 方便拖到 Netlify)
```

## 部署

`deploy/` 文件夹是直接可以上传的版本。任意静态托管都行:

- **Netlify Drop**: 拖 `deploy/` 到 https://app.netlify.com/drop
- **Netlify 站点**: 在项目 Deploys 页拖 `deploy/` 覆盖
- **其他** (Vercel / GitHub Pages / 腾讯云静态网站) 同样适用

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript, **无后端**
- 无任何依赖库, 不需要 npm install
- localStorage 存方案
- 兼容所有现代浏览器 (Chrome / Edge / Safari / Firefox / 微信内置)
